## What it does

`GET /api/route/?start=Dallas, TX&finish=Chicago, IL` returns the route as GeoJSON, the stops where the truck should buy fuel, how much to buy at each, and what it costs. The truck leaves with a full tank, so a trip under 500 miles needs no stops.

Three choices carry the design:

- **One routing call.** OSRM returns the full route geometry in a single request. Locations written as `City, ST` or `lat,lon` resolve against a local Census table, so they cost nothing.
- **Offline geocoding.** The price CSV has no coordinates. Stations are placed at their city's Census centroid, computed once by `load_stations`.
- **An exact optimizer that counts stops.** A dynamic program over (station, fuel) minimises fuel cost plus $15 per stop, so NYC → LA takes 7 stops instead of 16 for $4 more fuel. It runs in about 20 ms. See [How the optimizer works](/docs/optimizer).

## The response at a glance

```json title="GET /api/route/?start=Dallas, TX&finish=Chicago, IL"
{
  "start":  { "query": "Dallas, TX", "lat": 32.78, "lon": -96.8 },
  "finish": { "query": "Chicago, IL", "lat": 41.88, "lon": -87.63 },
  "distance_miles": 925.4,
  "duration_hours": 13.6,
  "fuel_stops": [
    { "mile": 412.3, "name": "PILOT #123", "address": "I-44, EXIT 283", "city": "Big Cabin",
      "state": "OK", "lat": 36.53, "lon": -95.22, "price": 3.007, "gallons": 31.2, "cost": 93.82 }
  ],
  "total_gallons_purchased": 42.5,
  "total_fuel_cost": 130.53,
  "cost_of_fuel_consumed": 284.22,
  "stop_penalty": 15.0,
  "route": { "type": "LineString", "coordinates": [[-96.8, 32.78], "…"] },
  "map_url": "https://<host>/api/route/map/?start=Dallas%2C+TX&finish=Chicago%2C+IL&stop_penalty=15.0",
  "external_api_calls": 1
}
```

| Field | Meaning |
| --- | --- |
| `total_fuel_cost` | USD spent at stops. Starts from a full tank, so short trips report `0`. |
| `cost_of_fuel_consumed` | Gallons burned over the whole trip × average price paid, or the cheapest corridor price when nothing is bought. `null` only if the corridor has no station at all. |
| `stop_penalty` | USD per stop used to choose the stops (query parameter, default `15`). Not included in `total_fuel_cost`. |
| `external_api_calls` | `1` on a typical cold request, up to `3` with Nominatim fallbacks, `0` on a cache hit. |
| `map_url` | An HTML map of the same trip. Reads the cache, so it adds no calls. |
